# 💣 Game Minesweeper 2D - Đồ án PBL2

Một tựa game dò mìn kinh điển được phát triển bằng ngôn ngữ C++ kết hợp cùng thư viện đồ họa SFML 3.0. 

<img width="1280" height="720" alt="Home" src="https://github.com/user-attachments/assets/153ee1e7-5b2b-4eb8-bf13-3d56d663764d" />

## 🌟 Tính năng nổi bật
* Giao diện đồ họa trực quan, quản lý tài nguyên mượt mà.
* Tích hợp âm thanh, nhạc nền sinh động.
* Thuật toán loang mìn (Flood-fill) chuẩn xác.
* Hỗ trợ cắm cờ và đếm ngược thời gian.

## 🛠️ Công cụ & Công nghệ
* **Ngôn ngữ:** C++17
* **Đồ họa & Âm thanh:** Thư viện SFML 3.0
* **Build tool:** CMake / GCC
